# Content Warning Archipelago Randomizer

## What is Archipelago?
Archipelago is a multi-game open-source randomizer that combines a variety of games into a single multiplayer experience. More information at https://archipelago.gg/

## Multiworld Setup Instructions
1. Download the latest `content_warning.apworld` file from our GitHub releases here https://github.com/Jakeodude/cw-apworld.
2. Follow the instructions on https://archipelago.gg/tutorial/Archipelago/setup/en on generating a game. Note that you will have to place the `.apworld` file in the `lib/worlds` folder of your Archipelago install and generate the world locally.
3. Using the Archipelago.gg website or a local machine, host a server using the output file generated.

## Thunderstore Install Instructions (Recommended)
1. Install a mod manager like the Thunderstore Mod Manager or r2modman.
2. Install the **Content Warning Archipelago** mod and all of its dependencies by clicking on "Install with Mod Manager" on our Thunderstore page. *(This will automatically install BepInEx and MyceliumNetworking).*
3. Click the **Run Modded** button to launch *Content Warning*.
4. Wait a few seconds on the main menu for the Archipelago connection panel to appear.
5. Enter your Archipelago server address/port, your player slot name, and the server password (if any), then click **Connect**.
6. After a successful connection, host a new game and begin playing!

## Manual Client Install Instructions
1. Download version 5.4.2100 of BepInEx from Thunderstore.
2. Follow the instructions on Thunderstore to manually install BepInEx into your *Content Warning* game folder.
3. Run *Content Warning* once so BepInEx can complete its initial setup.
4. Download the latest release of the Content Warning Archipelago client plugin.
5. Extract the `.dll` file into your `BepInEx/plugins` folder.
6. Download **MyceliumNetworking** by Rugbug Redfern from Thunderstore and add it to your `plugins` folder as well.
7. Launch *Content Warning*.
8. Wait a few seconds on the main menu for the Archipelago connection panel to appear.
9. Enter your Archipelago server address/port, your player slot name, and the server password (if any), then click **Connect**.
10. After a successful connection, host a new game and begin playing!

## Randomized Items
* Money
* Meta Coins
* Player Upgrades (Stamina, Camera, and Oxygen)
* Diving Bell Upgrades (Item Recharging and Oxygen Recharging)
* View Multipliers
* Traps (Monster and Ragdoll)

## Randomized Locations
* Buying items in the shop
* Buying hats
* Filming monsters and artifacts
* Reaching specific Quotas and View Totals
* Completing Sponsorships
* Finding Chorbies *(Note: The mod modifies the game so that at least one Chorby is guaranteed to spawn on each dive!)*

## Known Issues
* Multiplayer lobbies may occasionally experience visual desyncs with items and UI overlays.
